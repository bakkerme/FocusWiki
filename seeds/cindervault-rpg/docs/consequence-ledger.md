# Consequence Ledger & Resonance Clocks

> **Illustrative Prototype Content:** Synthetic reference rules for the fictional *Cindervault* tabletop/engine sample repository.

Every sealed vault sector tracks a four-segment **Ward Resonance** clock (`0/4` through `4/4`). Failed or strained threshold actions advance this clock; deliberate grounding rituals reduce it.

## Resonance Tiers

| Clock State | Ambient Sign | Mechanical Effect |
| :--- | :--- | :--- |
| `0/4` Dormant | Cold copper seams | Baseline ward tier penalties apply |
| `1/4` Hum | Faint ozone scent | No penalty; warning telegraph for delve team |
| `2/4` Charged | Hair-thin blue arcs | Metal armor suffers `-1` on nimble dodges |
| `3/4` Critical | Resonant chime | Next `≤6` breach triggers immediate discharge |
| `4/4` Discharge | Vault-wide pulse | Awakes dormant sentinels; resets clock to `1/4` |
